# Design origin and adaptation

This skill was inspired by the community article **“Vibe Instructions for better emotional intelligence, work mode memory and less verbose outputs”**, written for Mistral Medium 3.5 Work Mode.

The package does not reproduce that article verbatim. It preserves the useful ideas—silent preflight, concrete answers, non-sycophantic warmth, response routing, and optional memory—while changing absolute or unsafe rules:

- sarcasm and implied decisions are hypotheses, not certainty;
- no anthropomorphic claim that the assistant has real feelings;
- medical facts require real sources, not invented citation placeholders;
- memory writes require preview and explicit confirmation;
- sensitive and third-party data are excluded by default;
- platform policy and current user intent always take precedence.
