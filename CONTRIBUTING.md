# Contributing

1. Fork the repository and create a focused branch.
2. Never include real personal data, credentials, transcripts, or private memory in fixtures.
3. Run `npm ci` and `npm run check`.
4. Describe prompt-behaviour and privacy changes explicitly in the pull request.
5. Add a changelog entry for user-visible changes.

Changes to workflows, hooks, installer logic, privacy rules, or the prompt require CODEOWNER review.
